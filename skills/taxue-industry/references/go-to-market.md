# 上市策略 — 先打哪、怎么说、走什么渠道

> 工具：GTM 四步框架 + 北极星人群。
> 出口：上市计划（GTM panel）。

## 核心问题

1. 先打哪个市场？（不是所有市场一起打）
2. 对谁说话？（北极星人群）
3. 说什么？（核心信息 + 真实语言）
4. 走什么渠道？（触点匹配）

## GTM 四步框架

### ① 选北极星市场
- 用用户面板找「最痛 + 最易触达」的子群
- 标准：痛点强 × 渠道可达 × 竞争弱 × 传播潜力
- **先赢一个小市场，再扩散**

### ② 锁定北极星人群
- 从用户面板选 1 个细分人群（不是全部）
- 这一群人的画像细节 = 上市素材的输入

### ③ 核心信息（value proposition）
```
为 [北极星人群]
解决 [最痛痛点] 
通过 [独特机制]
不同于 [竞品]
```

### ④ 渠道匹配（人群 × 触点）
| 人群行为 | 渠道 | 内容形式 |
|---------|------|---------|
| 画像里的触达渠道 | 对应平台 | 他们说话的方式 |
| 决策路径里的信息源 | 种草/评测/推荐 | 对应内容类型 |

**用画像的 language 维度写文案**：用户自己的话术是最有效的传播语言。

## GTM 面板 schema

```json
{
  "slug": "gtm-gen-z-gaming",
  "name": "Z世代手游上市计划",
  "north_star_market": "…",
  "north_star_persona": "gen-z-gamers",
  "value_proposition": {
    "for": "…", "who": "…", "that": "…", "unlike": "…"
  },
  "channels": [
    {"platform": "小红书", "content": "游戏切片+真实玩家测评", "evidence": "用户面板触达渠道"}
  ],
  "launch_metrics": ["首月下载", "次周留存", "付费转化"],
  "timeline": "30-60-90"
}
```

## 判断纪律

1. **先窄后宽**：GTM 不是覆盖所有人，是赢下北极星人群。
2. **用用户的语言**：文案来自画像 language 维度，不用行业黑话。
3. **渠道跟着用户走**：用户在哪，渠道就在哪，不追热点平台。
4. **上市可度量**：launch_metrics 必须是可数的（下载/留存/转化）。

## 停止条件

- 北极星市场 + 人群已选定
- 核心信息一句话说得清
- 渠道 × 内容匹配了用户行为
- 有可度量的上市指标
