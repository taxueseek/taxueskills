# 市场分析 — 这个市场值不值得进

> 工具：TAM/SAM/SOM 三层测算 + 市场趋势判断。
> 出口：市场面板（market panel）。

## 核心问题

1. 市场有多大？（TAM/SAM/SOM 分层）
2. 在涨还是在跌？（趋势与驱动因素）
3. 值不值得进？（规模 × 增速 × 竞争密度 × 我们的优势）

## TAM/SAM/SOM 测算

| 层 | 定义 | 估算方法 |
|----|------|---------|
| **TAM** | 总可寻址市场（理论全部） | 人数 × 客单价，或行业报告引用 |
| **SAM** | 可服务市场（我们能力范围内） | TAM × 地理/渠道/能力过滤 |
| **SOM** | 可获得市场（现实能拿到的份额） | SAM × 合理市场份额假设 |

**每个数字必须标注**：
- 来源（行业报告/推算/假设）
- 口径（是 TAM 还是 SAM，别混）
- 时间（哪一年的数据）

## 市场趋势判断框架

| 信号 | 看什么 |
|------|--------|
| 需求侧 | 搜索量趋势、社媒讨论量、竞品增长 |
| 供给侧 | 新进入者数量、融资热度、巨头是否入场 |
| 替代风险 | 新技术/新习惯是否在消灭这个需求 |
| 政策环境 | 监管松紧、合规成本 |

## 市场面板 schema

```json
{
  "slug": "market-gen-z-gaming-cn",
  "name": "中国Z世代手游市场",
  "tam": {"value": "800亿", "source": "行业报告", "year": 2025},
  "sam": {"value": "200亿", "source": "推算", "note": "仅休闲向"},
  "som": {"value": "5亿", "source": "假设", "note": "份额2.5%"},
  "trend": "增长中/平稳/萎缩",
  "drivers": ["驱动因素1", "驱动因素2"],
  "risks": ["风险1", "风险2"],
  "verdict": "值得进/谨慎/不进 + 理由",
  "evidence": ["来源链接"]
}
```

## 判断纪律

1. **区分事实与口径**：市场数据是「估计」不是「事实」，永远标注来源和方法。
2. **警惕大数字陷阱**：TAM 800 亿很诱人，但 SOM 才是你真正能拿到的。
3. **增速比规模重要**：萎缩的大市场不如增长的小市场。
4. **给出明确判断**：市场面板必须有 `verdict`，不含糊。

## 停止条件

- TAM/SAM/SOM 三层都有数字和来源
- 趋势判断有证据支撑
- 有明确 verdict（进/谨慎/不进）
