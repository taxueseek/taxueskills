# ⑥ 访谈/小组讨论 — 用真实对话验证画像

> 工具：访谈提纲生成 + 小组讨论协议。
> 出口：验证记录 + 画像修订。

## 何时必须做

- 画像置信度是 L1（探索性）
- 决策成本高（要投钱/投人做产品）
- 关键假设无外部证据，只能问真人

## 访谈提纲生成（3 层结构）

### 第 1 层：破冰与背景（5 分钟）
- 让对方放松，了解基本背景
- 问题示例：「你最近一次遇到 X 情况是什么时候？」

### 第 2 层：核心探究（20 分钟）
- 围绕画像的待验证假设提问
- **技巧**：用「讲故事」引导——「给我讲一次你…」比「你会不会…」有效
- 每个假设准备 2 个角度的问题（正面问 + 侧面问）

### 第 3 层：假设验证（5 分钟）
- 直接验证画像草案里的关键属性
- 「有人说 X，你同意吗？为什么？」

## 访谈纪律

1. **多听少说**：访谈 80/20 法则，让被访者说 80%。
2. **不引导**：禁止「你是不是觉得…」这种带答案的问题。
3. **追问细节**：听到泛泛而谈就追问「能举个具体例子吗？」。
4. **记录原话**：关键回答逐字记录，作为画像证据。

## 小组讨论协议（焦点小组）

| 要素 | 建议 |
|------|------|
| 人数 | 5-8 人（太少没讨论，太多每人说得少） |
| 时长 | 60-90 分钟 |
| 主持人 | 1 人引导 + 1 人记录（或录音转写） |
| 结构 | 破冰 → 主题讨论 → 概念反馈 → 总结 |
| 禁忌 | 不让个别人主导、不评判任何回答 |

## 验证输出

```yaml
hypothesis_verified:
  - hypothesis: "原假设"
    result: "验证/推翻/部分验证"
    evidence: "访谈记录/quote"
image_revision:
  - dimension: "修改的维度"
    change: "从什么变成什么"
    reason: "为什么"
confidence_after: "L1 → L2/L3"
```

## 停止条件

- 关键假设全部验证（或明确推翻并修订画像）
- 画像置信度升至 L2+
- 可以进入报告+面板（⑦）
