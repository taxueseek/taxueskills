# 竞品分析 — 谁在竞争、我们怎么赢

> 工具：竞品拆解框架 + 差异化定位。
> 出口：竞品面板（competitor panel）。

## 核心问题

1. 谁在竞争？（直接/间接/潜在）
2. 他们怎么打？（定位/定价/渠道/增长）
3. 我们的差异化机会在哪？

## 竞品分层

| 层 | 定义 | 例子 |
|----|------|------|
| **直接竞品** | 解决同一问题、同一人群 | 同类 App |
| **间接竞品** | 解决同一问题、不同方式 | 线下替代方案 |
| **潜在竞品** | 可能进入市场的玩家 | 巨头、上下游 |

## 竞品拆解框架（每个竞品填）

```yaml
name: "竞品名"
positioning: "他们的定位一句话"
target_user: "他们主打谁（对照用户面板）"
pricing: "价格/付费模式"
channels: "怎么获客"
strengths: ["优势1", "优势2"]
weaknesses: ["弱点1", "弱点2"]
evidence: ["来源链接"]
```

## 差异化定位（竞品 × 用户需求矩阵）

把用户面板的痛点/动机 × 各竞品覆盖情况做成矩阵：

| 用户需求 | 竞品A | 竞品B | 我们 |
|---------|-------|-------|------|
| 痛点1 | ✅ 覆盖 | ❌ 空白 | 机会 |
| 痛点2 | ❌ 空白 | ✅ 覆盖 | 差异化 |
| 动机1 | ⚠️ 部分 | ⚠️ 部分 | 改进 |

**机会 = 用户有需求 + 竞品都空白**。这是商业上最值钱的格子。

## 竞品面板 schema

```json
{
  "slug": "competitors-gen-z-gaming",
  "name": "Z世代手游竞品",
  "competitors": [
    {"name": "竞品A", "positioning": "…", "target_user": "…", "pricing": "…", "strengths": [], "weaknesses": [], "evidence": []}
  ],
  "opportunity_matrix": {
    "痛点1": {"competitor_a": true, "competitor_b": false, "us": "机会"},
    "痛点2": {"competitor_a": false, "competitor_b": true, "us": "差异化"}
  },
  "verdict": "差异化方向 + 理由"
}
```

## 判断纪律

1. **至少 3 个竞品**才有比较价值（直接+间接）。
2. **弱点要来自证据**：用户吐槽/差评/数据，不是我们猜的。
3. **差异化要可执行**：「更好」不是差异化，「在用户最痛的空白上做到最好」才是。
4. **竞品信息标注时间**：市场变化快，3 个月前的信息要注明。

## 停止条件

- 直接+间接竞品 ≥3 个，各有完整拆解
- 需求×竞品矩阵填充完
- 有明确差异化 verdict
