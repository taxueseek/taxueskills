# ③ 搜索画像 — 拉取已有数据与内部洞察

> 数据入口：`{个人记忆}` = entries.industry_memory，`{研究资料}` = entries.industry_research（读 `~/.taxue/config.json`，解析规范见 `../taxue/references/vault.md`）。入口未配置时跳过内部资产，只用公开数据。

> 工具：数据源清单 + 已有面板检索。
> 出口：已有证据汇总。

## 目的

不是从零开始，而是**站在已有数据上**。研究前先穷尽现有证据，避免重复劳动。

## 数据源清单（按优先级）

### 内部资产（先查这些）
1. `panels/index.json` — 本技能已有面板
2. `{个人记忆}`（入口 industry_memory）— 个人观察沉淀
3. `{研究资料}`（入口 industry_research）— 历史研究报告
4. 项目内 `research/`、`insights/` 目录

### 公开数据（按需）
1. 行业报告（艾瑞/QuestMobile/Gartner 摘要）
2. 电商评价（京东/淘宝评论区 = 真实用户语言）
3. 应用商店评论（App Store / 应用宝）
4. 问答平台（知乎/小红书相关话题）
5. 新闻与财报（公司官方口径）

### 网络工具（优先级）
1. argo CLI（本机已装，约 110 引擎，TF-IDF 路由）
2. web_search / web_fetch
3. 具体平台抓取（小红书/微博等见 `social-scan.md`）

## 证据汇总模板

```markdown
## 已有证据
### 内部资产
- [来源] [要点] [可信度]
### 公开数据
- [来源链接] [要点] [可信度]
### 证据缺口
- [关键问题还没有证据]
```

## 关键原则

1. **每条证据标注来源**，可信度分级（一手/二手/传闻）。
2. **区分事实与推断**：事实直接引用，推断必须标注「推断自…」。
3. **找到缺口就停**：证据汇总的目的是定位缺口，不是堆砌资料。

## 停止条件

- 内部资产已穷尽检索
- 证据缺口明确列出
- 可以进入社媒扫描（④）补缺口
