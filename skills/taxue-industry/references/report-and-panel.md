# ⑦ 报告+面板 — 输出当前答案 + 沉淀可复用资产

> 工具：报告模板 + 面板落盘。
> 出口：研究报告 + **可复用 AI 用户画像面板**。

## 核心心智

**报告回答当前问题，面板回答未来所有问题。** 报告可以扔，面板必须沉淀。这是本技能与普通研究技能的根本区别。

## 研究报告模板

```markdown
# 用户研究报告：<主题>

## 决策摘要（1 屏）
- 核心结论
- 对决策（验证想法/产品设计/竞品/上市）的直接含义
- 置信度

## 目标用户是谁
- 引用面板核心画像（不是重写）

## 关键洞察（每条带证据）
- 洞察 1 [来源]
- 洞察 2 [来源]

## 对决策的建议
- 建议 1 / 建议 2

## 证据附录
- 语料来源 / 访谈记录 / 数据报告
```

## 面板落盘（必做）

1. 画像 JSON 写入 `panels/<audience-slug>.json`
2. 通过校验：`python3 scripts/validate_panel.py panels/<audience-slug>.json`
3. 更新 `panels/index.json` 注册表（slug / 人群 / 置信度 / 创建时间 / 复用场景）
4. 更新 `CHANGELOG.md`

## 面板复用场景（下次回来怎么用）

| 新问题 | 复用方式 |
|--------|---------|
| 验证一个想法 | 用面板判断目标人群是否有此痛点 |
| 设计产品概念 | 用面板的痛点/动机/行为做设计输入 |
| 分析竞争对手 | 面板对比：竞品满足/未满足哪些画像需求 |
| 制定上市计划 | 用面板的语言/话术/渠道做传播策略 |

## 面板质量门禁

- 7 维全部填充
- 每维 ≥2 条证据
- 置信度 ≥ L2（否则标注「探索性，未经验证」）
- 通过 schema 校验脚本

## 停止条件

- 报告回答了决策问题（不是堆资料）
- 面板已落盘 + 注册 + 校验通过
- 用户知道下次怎么回来复用面板
