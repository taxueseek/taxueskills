# ⑤ 构建画像 — 把语料变成结构化 AI 用户画像

> 工具：画像生成器 + 7 维画像模板。
> 出口：AI 用户画像草案（符合 panel-schema）。

## 从语料到画像（三步法）

```
原始语料（④的输出） → 主题聚类 → 维度填充 → 画像草案
```

1. **主题聚类**：把 20+ 条语料按主题归类（痛点/动机/行为/语言/决策）
2. **维度填充**：每个维度从语料中提取证据，禁止凭空推断
3. **画像草案**：生成符合 `panel-schema.md` 的 JSON，标注每条的证据来源

## 7 维画像模板

| 维度 | 问什么 | 证据来源 |
|------|--------|---------|
| ① 身份与场景 | 他们是谁？在什么场景下遇到这个问题？ | 社媒自述、个人资料 |
| ② 痛点与挫折 | 他们在抱怨什么？什么让他们放弃？ | 负面评论、吐槽帖 |
| ③ 动机与目标 | 他们真正想要什么？为什么？ | 正面表达、求助帖 |
| ④ 行为与习惯 | 他们怎么解决问题？用什么工具？ | 使用分享、教程 |
| ⑤ 决策路径 | 从注意到问题到采取行动，经过什么？ | 购买分享、求助流程 |
| ⑥ 语言与话术 | 他们怎么描述这个问题？（原话） | 评论原文、标题 |
| ⑦ 反画像 | 谁不是目标用户？（防止画像泛化） | 排除性证据 |

## 画像置信度评级

| 等级 | 标准 | 能否发布 |
|------|------|---------|
| **L1 探索性** | 仅桌面研究，无验证 | 不能发布，需⑥验证 |
| **L2 已验证** | 访谈/小组验证过关键假设 | 可发布 |
| **L3 高置信** | 多源交叉验证 + 量化佐证 | 可发布，可跨项目复用 |

## 画像中的证据纪律

- 每条画像属性标注 `evidence: "来源URL或访谈记录ID"`
- 无证据的属性标注 `evidence: "推断"` 并标低置信度
- **禁止**：把研究者自己的假设写进画像当事实

## 输出

`panels/<audience-slug>.json`，符合 `panel-schema.md`，通过 `scripts/validate_panel.py` 校验。

## 停止条件

- 7 维全部填充，每维有 ≥2 条证据
- 置信度已评级
- 面板通过 schema 校验
