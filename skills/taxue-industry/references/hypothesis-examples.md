# 假设树示例

## 示例1：新能源行业

**研究问题**：新能源行业的核心竞争逻辑是什么？

```
假设树：
├── H1：政策驱动是行业第一推动力
│    → 验证方向：补贴退坡后的市场表现、政策变化与装机量相关性
│    → 初始置信度：高
│
├── H2：成本下降已让行业进入市场化自循环
│    → 验证方向：光伏/风电的度电成本趋势、无补贴项目占比
│    → 初始置信度：中
│
├── H3：行业过剩产能正在出清，集中度将大幅提升
│    → 验证方向：企业淘汰率、CR5 市占率变化、落后产能关停数据
│    → 初始置信度：中
│
└── H4：储能是下一个真正的增长瓶颈和机会
     → 验证方向：储能装机增速、政策支持力度、技术路线竞争
     → 初始置信度：低
```

## 示例2：AI 应用行业

**研究问题**：AI 应用层的商业模式是否成立？

```
假设树：
├── H1：ToB SaaS 是 AI 应用最可行的商业模式
│    → 验证方向：AI SaaS 的 ARR 增速、客户留存率、LTV/CAC
│    → 初始置信度：高
│
├── H2：ToC 订阅制在 AI 领域走不通
│    → 验证方向：ChatGPT/Claude 之外的 ToC AI 产品留存数据
│    → 初始置信度：中
│
├── H3：真正的价值在垂直场景，不在通用大模型
│    → 验证方向：垂直 AI 企业的融资/营收表现 vs 通用大模型企业
│    → 初始置信度：中
│
├── H4：AI 应用的网络效应弱于传统 SaaS
│    → 验证方向：用户切换成本、数据飞轮是否存在、头部产品市占率
│    → 初始置信度：低
│
└── H5：当前估值已透支未来 3-5 年增长
     → 验证方向：PS 倍数对比、营收增速 vs 估值增速
     → 初始置信度：中
```

## 示例3：消费行业（新茶饮）

**研究问题**：新茶饮行业的终局格局是什么？

```
假设树：
├── H1：行业将走向寡头垄断（3-5 家主导）
│    → 验证方向：对比咖啡行业格局、头部品牌市占率趋势
│    → 初始置信度：中
│
├── H2：下沉市场是未来主要增量
│    → 验证方向：三四线城市开店增速、客单价接受度、品牌下沉策略
│    → 初始置信度：高
│
├── H3：加盟模式优于直营（规模效率 > 品控风险）
│    → 验证方向：头部品牌加盟/直营比例、单店盈利模型对比
│    → 初始置信度：中
│
└── H4：产品同质化将导致价格战持续
     → 验证方向：客单价趋势、毛利率变化、新品迭代速度
     → 初始置信度：高
```

## 假设生成原则

### 好的假设

- **可证伪**：有明确的验证路径，能被证据推翻
- **有张力**：不同假设之间存在竞争关系，不是同一观点的变体
- **有层次**：覆盖不同维度（规模、结构、驱动、风险）
- **有方向**：每个假设都指向不同的搜索策略

### 差的假设

- **不可证伪**：「XX 行业有发展前途」——这没法证伪
- **没有张力**：所有假设都是「XX 行业会增长」的不同说法
- **太宽泛**：「XX 行业受多种因素影响」——废话
- **没有验证路径**：「XX 行业的本质是……」——怎么验证？

### 假设数量

- 简单行业：3 个假设
- 中等复杂度：4 个假设
- 高复杂度：5 个假设
- 不要超过 5 个，否则验证成本太高
