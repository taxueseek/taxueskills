# 搜索策略参考

## 搜索能力分层（引擎 B）

| 能力 | 用法 | 适用 |
|------|------|------|
| argo（推荐） | `argo job "<岗位> <城市>"` 招聘多平台聚合（BOSS/猎聘/智联/前程无忧/597/今日招聘/ncss） | 全平台岗位搜索首选 |
| argo search | `argo search "site:zhipin.com <岗位> <城市>"`，TF-IDF 路由多引擎 + RRF 融合 | 补充特定平台/公告检索 |
| 基础搜索（无 argo） | web_fetch 直接抓平台站内搜索 URL 或公告页原文；无法直抓时用通用搜索 `site:` 查询 | 兑底方案 |

**检测**：`which argo` 命中即用 argo；未命中用基础搜索，不要尝试安装。

**argo job 输出**：带平台标签（●[智联招聘] ●[猎聘] ●[BOSS直聘]）的岗位标题 + 详情链接，可直接做来源标注与交叉验证。

**引擎 A（腾讯）不依赖 argo**，走 `scripts/` 下官方 API 脚本（见 tencent-engine.md）。

## 搜索关键词模板

- `{地区} {企业类型} 公开招聘 {学历} {年份}`（年份用当次搜索时的当前年份，不要写死）
- `{地区} {企业类型} 招聘 {学历} 报名`
- `{地区} 人才考试服务平台 招聘公告`
- `{地区} 国资委 招聘 {时间}`
- `{企业名} 招聘 {时间}`
- `{行业} {企业类型} {地区} 招聘`
- `fjsrlzy.cn {地区} 招聘`（福建省国企）
- `iguopin.com {地区}`（国聘平台）

## 时效性判断

1. 搜索结果日期距今超过 30 天，大概率已截止
2. 没有明确报名时间的，不可信——标注需核实
3. 有「递补」「补录」字样，说明第一批已结束，但还有机会
4. 校招关注春招（3-5 月）/秋招（9-11 月）
5. 社招全年，金三银四、金九银十为高峰期

## 学历匹配

| 岗位要求 | 专科可报？ | 备注 |
|---------|-----------|------|
| 大专及以上 | 可报 | — |
| 专科及以上 | 可报 | — |
| 本科及以上 | 不可报 | — |
| 全日制本科及以上 | 不可报 | 专升本/自考需谨慎 |
| 有证书/职称要求 | 视情况 | 持证者也有竞争力 |

岗位要求表通常有附件（XLS/PDF），建议用户下载逐条核对。

## 用工形式区分

国企/事业单位公告中必须区分：

| 用工形式 | 稳定性 | 备注 |
|---------|--------|------|
| 正式编制/正式职工 | 最高 | 竞争最激烈 |
| 合同制/劳动合同 | 较高 | 同工同酬常见 |
| 劳务派遣 | 较低 | 与第三方签合同，待遇通常较低 |
| 临时聘用/项目制 | 最低 | 短期，稳定性最差 |

## 商业平台搜索策略（互联网/科技/民企）

当用户找的是互联网、科技、民企岗位时，优先用商业招聘平台。

### 搜索词构造

| 场景 | 搜索词模板 | 示例 |
|------|-----------|------|
| 通用搜索 | `site:{平台} {岗位} {城市} {经验}` | `site:zhipin.com Java后端 北京 3年` |
| 搜特定公司 | `site:{平台} {公司名} {岗位}` | `site:zhipin.com 字节跳动 前端` |
| 搜薪资范围 | `site:{平台} {岗位} {城市} {薪资}K` | `site:zhipin.com 算法工程师 上海 40K` |
| 搜远程岗位 | `site:eleduck.com {岗位}` 或 `site:{平台} {岗位} 远程` | `site:eleduck.com 后端开发` |
| 搜内推 | `site:nowcoder.com {公司} 内推` | `site:nowcoder.com 美团 内推` |
| 搜面经 | `site:nowcoder.com {公司} {岗位} 面经` | `site:nowcoder.com 阿里 Java 面经` |

### 与政府招聘搜索的区别

| 维度 | 政府/国企招聘 | 商业平台招聘 |
|------|-------------|-------------|
| 信息来源 | 官方公告、国资委 | 平台职位页 |
| 时效性 | 报名截止日期明确 | 职位随时下架，无明确截止 |
| 交叉验证 | 多平台同一岗位合并 | 同一公司多岗位列出 |
| 详情获取 | web_fetch 抓公告原文 | web_fetch 抓职位详情页 |
| 薪资 | 公告中可能有 | 平台直接展示范围 |
