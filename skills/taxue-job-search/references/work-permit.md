# 工作准证核验（按需读取）

> 仅在用户求职地需要工作准证时读取：新加坡（EP / S Pass / Work Permit）、港澳、海外。
> 中国大陆的国企、事业单位、民企岗位不涉及准证，不要套用本文件的规则。

用户有签证、准证或工作许可要求时，分开核验：

1. 职位是否仍在招；
2. 薪资等硬条件是否满足官方门槛；
3. 招聘页或雇主是否明确表示提供 sponsorship / 可办理准证。

前两项不能推出第三项。雇主规模、历史先例和「有申请能力」也不能证明当前岗位支持准证，不应写入岗位判断。没有当前岗位的明确证据，只能写「准证支持未确认，申请前向雇主核实」。

官方最低薪资只是必要条件之一。未核验候选人年龄对应的合格薪资门槛、岗位薪资和 COMPASS / 配额等条件时，禁止写「硬条件满足」或「符合 EP / S Pass」；只能列官方规则和待确认项。

政策金额、资格和生效日期必须在当次搜索中打开政府官方页面核验，并附官方链接与核验日期。打不开官方页就不写具体金额，只给核验入口。不得沿用示例、模型记忆或旧报告中的政策数字。
