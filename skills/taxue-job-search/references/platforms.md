# 招聘平台速查表

> 按来源类型分组。搜索时根据用户的企业类型和行业选择对应平台。
> 腾讯系岗位优先走引擎 A（官方 API 直连，见 tencent-engine.md），其余平台走引擎 B。

## A：政府/官方公共平台（权威优先）

| 平台 | 网址 | 适用 |
|------|------|------|
| 中国公共招聘网 | `job.mohrss.gov.cn` | 人社部平台，央企校招、名企招聘 |
| 就业在线 | `jobonline.cn` | 人社部全国招聘求职 |
| 国家大学生就业服务平台 | `ncss.cn` | 应届生、央企校招 |

搜索词模板：
- `{地区} {企业类型} 公开招聘 {学历} {时间}`
- `{地区} 人力资源和社会保障局 招聘`
- `{地区} 人才考试服务平台 招聘公告`

## C：综合招聘平台（商业）

| 平台 | 网址 | 适用 | 搜索词模板 |
|------|------|------|-----------|
| BOSS 直聘 | `zhipin.com` | 互联网/科技/民企，直聊模式 | `site:zhipin.com {岗位} {城市} {经验}` |

| 猎聘 | `liepin.com` | 中高端/外企/高薪民企 | `site:liepin.com {岗位} {城市}` |
| 拉勾网 | `lagou.com` | 互联网垂直，创业公司多 | `site:lagou.com {岗位} {城市}` |

| 牛客网 | `nowcoder.com` | 面经/校招/内推信息 | `site:nowcoder.com {公司} {岗位} 面经` |
| LinkedIn | `linkedin.com` | 外企/跨国/中高端 | `site:linkedin.com {岗位} {城市}` |

**搜索词组合技巧：**
- 搜特定公司：`site:zhipin.com 字节跳动 后端开发`
- 搜薪资范围：`site:zhipin.com {岗位} {城市} 30K`
- 搜远程岗位：`site:zhipin.com {岗位} 远程` 或 `site:eleduck.com {岗位}`
- 搜内推：`site:nowcoder.com {公司} 内推` 或 `site:maimai.cn {公司} 内推`

## G：社交媒体/公众号/小程序

- 搜索「{地区} {企业类型} 招聘 公众号」
- 搜索「{地区} 国企 线上报名 {年份}」（年份用当次搜索时的当前年份，不要写死）
- 微信搜索「{地区} 招聘」小程序
- 抖音/快手/小红书：直播招聘、短视频招聘

## H：企业官网

- 已知该地区重点企业，直接搜索 `{企业名} 招聘`
- 本地国企/城投/交投/水务集团官网通常有「人才招聘」栏目

## I：官方 API 直连引擎（腾讯系）

| 平台 | 接口 | 适用 |
|------|------|------|
| 腾讯校招官网 | `join.qq.com/api/v1`（无需鉴权） | 腾讯系校招/实习/青云岗位、官方公告、宣讲会 |

用法：`python3 scripts/fetch_recruit_jds.py search --keyword "<岗位>"`，详见 `references/tencent-engine.md`。

## 按意图域选择来源

| 意图域 | 首选来源 | 辅助来源 | 不适用于 |
|--------|---------|---------|---------|
| 国企/央企 | 国聘网 + 国资委 + 央企官网 | 智联、地方国企平台 | 外企/互联网/民企 |
| 外企/MNC | 神仙外企 + LinkedIn | 猎聘外企、企业官网 | 国企/事业单位 |
| 互联网/科技 | BOSS 直聘 + 脉脉 | 拉勾、猎聘 | 国企/外企/传统 |
| 传统民企 | 51job + 智联 + BOSS | 58 同城（基层） | 国企/外企/金融 |
| 事业单位/编制 | 省人事考试局 + 人社局 | 公共招聘网、高校人才网 | 企业/外企 |
| 医疗 | 丁香人才 + 医药英才网 | 综合平台医疗频道 | 非医疗 |
| 教育 | 高校人才网 + 万行教师 | 综合平台教育频道 | 非教育 |
| 金融 | 金融英才网 + 51 金融圈 | 猎聘金融频道 | 非金融 |
| 校招/应届 | 牛客 + 实习僧 + ncss.cn | 国招网校招、企业校招 | 社招/中高端 |

| 蓝领/基层 | 58 同城 + BOSS 直聘 | 各地人才市场 | 白领/技术 |
