# 砍价策略指南

## 砍价的底层逻辑

砍价不是吵架，也不是比谁嗓门大。它是一场信息博弈——你对卖家的成本和底线知道得越清楚，你的位置就越有利。反之亦然。

**三条基本原理：**

第一，谁先报价谁吃亏。对方报出第一个价格之后，这个数字会成为后面谈判的心理基准线。所以尽量让对方先报价。如果对方非要你先说，就往低了说——你说的数字会成为对方心里的「这个顾客的出价基准」。

第二，卖家对「失去一单」的恐惧，大于对「多赚一点」的渴望。当卖家觉得这单要跑了的时候，让步的动力最大。所以永远保留一份「我随时可以走」的从容。

第三，卖家在你身上花的时间越多，就越舍不得放你走。讲解、演示、算价格——这些是卖家在你身上投入的时间成本。但记住，你的时间也是成本，不要缠斗太久，给自己设一个成交底线时间。

## 砍价之前必须做的三件事

**查线上底价。** 用慢慢买或什么值得买查同款产品的线上历史最低价。这个价格就是你砍价时的锚点——实体店的价格不应该比线上最低价高出太多。如果线下贵了超过 10%，直接问卖家为什么，亮出线上价格。

**查闲鱼行情。** 在闲鱼上搜同款产品的二手成交价。这不是为了买二手，而是为了了解这个商品真实的市场认可价值——二手价格的保值程度能反映品牌的真实口碑。

**比两到三家店。** 同样的产品在附近的两三家店里询价。让每家都知道你正在对比——但不要明说对方报了什么价。制造竞争压力，而不是激化卖家的敌意。

## 三级话术

### 第一级：任何场景适用

这三句话几乎可以应对所有的砍价场景：

第一步，问：「这个最低能给到什么价？」问完之后闭上嘴，等对方回答。沉默是你最有力的施压工具——人会本能地想填补沉默，而卖家填补沉默的方式往往是主动降价。

第二步，对方报价之后，轻轻说一句「嗯……有点高了」。然后继续沉默。如果对方主动降了价，说明还有空间。如果对方没有动，可能已经接近他的权限底价了。

第三步，「行，那我和家人商量一下，回头再来。」这是一个低压力、体面的离场方式。如果你转身时卖家挽留并给出更低价格，说明刚才的报价不是真正的底价。如果卖家痛快放手，说明确实谈到底了。

### 第二级：进阶策略

**以量换价。** 「这两件一起拿的话，能给到什么价？」先拿到多件的总优惠。然后问「那单件按同样的折扣比例算，应该多少？」——你没有承诺一定买两件，这只是谈价格的策略。

**制造参考价格。** 「我在附近另一家也看了，他们报的是 XX（比实际低 5-10% 的价格）。」这个操作的关键是不要指名道姓说出具体是哪家店，给对方台阶下。同时你的报价要比真实价格略低一些，给卖家一个「比竞争对手再好那么一点点」的空间。

**现金或全款。** 「我直接全款付了，能不能再少一点？」商家走刷卡或扫码支付通常要付 0.6-1% 的手续费，所以现金或一次性付全款对他们来说能省手续费。相应的，你可以要求再便宜 2-3%。但提醒一点：大件商品和需要保修的商品，最终还是要走正规支付留凭证——你可以用现金的由头谈价格，但实际付款时选择更有保障的方式。

### 第三级：高手策略

**找决策人。** 一线销售只有最低成交价权限，上面还有经理、店长、老板，每一层都有额外的一定比例的特批价空间。如果你跟销售谈到底了，礼貌地问：「这个价格你能完全做主吗？不能的话，帮我问问经理？」注意语气——这不是挑衅，是请求。

**样机和展品。** 「这个摆在外面的样机卖吗？能便宜多少？」家电样机能到六七折，家具展品能到五到七折，服装样衣四到六折（断码可能更低）。样品在法律上的保修义务和新品是一样的。如果外观有轻微瑕疵，可以作为进一步砍价的理由。

**不要赠品要折现。** 「赠品我不要了，直接给我折成现金优惠行不行？」赠品标价打五到六折，就是合理的折现金额。有一句要点：品牌送的赠品价值高于杂牌赠品，需要安装调试的赠品（比如安装服务）不要折现，比钱更值。

## 各品类砍价目标速查

| 品类 | 能砍到多少 | 突破口在哪 |
|------|-----------|----------|
| 大家电（连锁卖场） | 标价的 85-90% | 大促优惠叠加经理特批 |
| 大家电（品牌专卖） | 标价的 90-95% | 样机折扣、赠品折现、延保赠送 |
| 家具 | 标价的 60-70% | 标价虚高，大胆往六折砍 |
| 建材 | 标价的 50-70% | 量大可以更低，竞品店比价 |
| 手机和数码 | 基本砍不动 | 换贴膜、手机壳、延保、充电器等赠品 |
| 品牌服装 | 等商场活动 | 平时店员没有调价权限 |
| 黄金 | 工费能砍到 5-8 折 | 金价随大盘走砍不了，工费可以谈 |
| 二手车 | 标价的 85-90% | 检查出的瑕疵是砍价依据 |
| 眼镜 | 标价的 40-60% | 镜框和镜片分开谈，行业利润空间很大 |

## 绝对不能做的事

**在人多的时候大声砍价。** 卖家要维护店里的「价格形象」——如果旁边有其他顾客，降价给你就等于是给所有人降价。等到周围没人或者声音压低再谈。

**表现出一副非买不可的样子。** 一旦卖家从你的言行中判断出你一定会买，价格就再也谈不动了。永远带着一份「大不了不买」的心态。

**贬低商品本身。** 说「这个质量太差了」「做工这么粗糙」——这是在攻击对方的饭碗。正确的方式是称赞商品，但表示钱包有限。比如：「东西确实不错，但说实话超出我的预算了。」批评自己的经济实力，不批评对方的货品。

**付了定金之后再去砍尾款。** 定金等于合同，定了价就不要再谈了。所有的价格谈判，在付定金之前完成。同样，也不要跟熟人介绍的店家因为熟人就不砍价——熟人介绍不等于给了你最优价格，有时候反倒因为信任滤镜开了更高的价。

**如果卖家直接答应了你的第一次出价，说明你出高了。** 一个合理的砍价结果，双方都会在两三轮来回之后才达成。对方一口答应，意味着你的开价高于他的心理底线。
