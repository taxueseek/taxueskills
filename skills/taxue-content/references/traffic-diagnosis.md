## 前置认知：流量系统的三个真相

### 真相1：知识博主首先是学者

自我定位必须锚定在学者，再讨论流量。一旦反过来，流量焦虑会吞噬判断力，输出变成迎合而非求真。

### 真相2：流量是系统工程，不是玄学

六个环节，每一个都有可观测的结果，每一个都可以被分析、测试、迭代。没有哪个环节依赖灵感，全部依赖方法论。

### 真相3：你已有的素材就是最大的护城河

两套素材体系都可以为流量系统供弹：

- **踏雪素材库**（579条原子 + 金句弹药库 + 洞见观点库）：内容弹药

## 诊断流程

### 入口判断

```
用户带着什么来的？
├── 写了但没流量 → 先过「数据证据门」，数据够才定位环节；不够则补数据 + 做可逆实验
├── 有明确选题/内容 → 进入「环节诊断」
├── 不知道写什么 → 进入「选题课题」
└── 想系统性提升 → 走「六步完整诊断」
```

### 数据证据门

诊断时把三类东西分开：

- **用户数据**：可以直接计算和比较；
- **外部基准**：只有可核验来源、平台和日期时才能当基准；
- **当前推断**：必须标「推断」，并说明还缺哪个数据才能确认。

禁止用无来源的「行业平均」给指标判好坏。**指标之间默认不可互推、不可按百分比大小横向比较**：阅读量变化不能证明打开率变化，读完率不能单独证明开头合格，分享率不能单独证明选题有问题；只有共同分母、统计口径和计算公式齐全时才能换算。数据不足时，只用同一指标的账号历史值做纵向比较。

执行确定性门控：

| 数据状态 | 允许输出 |
|---------|---------|
| 至少一个指标有同口径历史值 | 先定位最上游的纵向异常，再设计单变量实验 |
| 只有当前截面指标，没有各指标历史值 | **禁止把某环节判为根因、禁止判合格/异常、禁止设无来源阈值**；补历史表，同时给一个最上游、可逆、低成本的单变量实验 |
| 只有「没人看」等感受，没有后台数据 | 暂不做「停掉」决定；导出近期同口径数据，同时给一个不依赖算法假设的入口实验 |
| 指标口径不清 | 先确认分子、分母和统计窗口；若用户要求行动，只给跨口径都安全的可逆实验 |

**不能诊断，不等于不能行动。** 信息不足时，把「根因结论」与「实验优先级」分开：可以优先测试最上游且容易控制的变量，但必须明确「这是为了获得证据，不代表它已被证明是瓶颈」。实验结果只和账号自身同指标历史中位数比较，不设行业阈值。

只有当前截面时，当轮必须同时交付两件事：

1. 补齐数据表：内容、发布日期、曝光或送达、打开/点击、读完、分享等平台实际可得字段；
2. 下周实验：固定选题类型、结构、发布时间等其他条件，只改一个入口变量（标题或封面），观察该变量对应的同口径指标相对账号历史是否改善。

拿到结果后才决定继续改入口、转向内容结构，还是停止当前方向。

## 课题 1：选题——找真问题

### 选题五问（至少满足 2 条才通过）

| # | 问题 |
|---|------|
| 1 | 读者看完能带走什么？（方法/判断/工具） |
| 2 | 你有独特信息吗？经历过的、验证过的、算出来的 |
| 3 | 你的认知和同行有差距吗？ |
| 4 | 有反共识成分吗？共识内容没有传播力 |
| 5 | 目标读者是谁？看完他们会做什么？ |
| 6 | **可实验性**：读者看完能立刻做可观测结果的实验吗？（工具/方法论类强制，叙事/情绪类跳过） |

### 选题驱动：让话题自带的东西决定诊断重点

不是所有选题都需要走过全部诊断维度。先看一眼这个话题本身带了什么——自带的东西是免费的，别花钱买已经有的：

| 话题自带 | 诊断重点 | 可以放过的 |
|---------|---------|-----------|
| 自带数据/案例 | 重点：数据冲击力够不够直接入标题？ | 不用额外制造认知差 |
| 自带反常识 | 重点：反常识点有没有被标题浪费？（如果标题没体现→一票否决） | 不用额外制造冲突 |
| 自带情绪/争议 | 重点：情绪有没有被命名？争议立场够不够锋利？ | 不用额外制造悬念 |
| 自带个人经历 | 重点：经历里的具体场景有没有被拉进开头？ | 不用额外建立可信度 |
| 什么都没自带 | 全部维度都要过，且优先用公式制造认知缺口 | — |

话题自带的东西，是选题阶段就定下来的竞争优势。诊断的任务是确保这个优势没有被浪费在平庸的标题和开头里。

### 选题七维效用评估

通过选题五问+第六问后，七维打分（1-5分，满分5.0）：

| 维度 | 含义 | 权重 |
|------|------|------|
| **强度** | 这个问题对读者有多痛？ | 0.20 |
| **持续时间** | 内容多久后还有用？（长青指数） | 0.15 |
| **确定性** | 你的判断有多少证据支撑？ | 0.20 |
| **邻近性** | 读者多久能感受到收益？ | 0.15 |
| **丰饶度** | 读完会不会带动更多好行为？ | 0.10 |
| **广度** | 多少人面临这个问题？ | 0.20 |

**效用总分** = 强度×0.20 + 持续时间×0.15 + 确定性×0.20 + 邻近性×0.15 + 丰饶度×0.10 + 广度×0.20

阈值：≥ 3.8 优先做 | 3.0-3.7 优化低分维度后做 | < 3.0 换选题或换角度

> **注意**：此为工具/方法论类评估框架。叙事/情绪类内容走另一维度（表达精准度、场景代入感、情绪强度、可分享性）。先判定内容类型再选框架。

### 素材库选题法

从原子库中检索选题素材：

```bash
# 按标签检索相关原子
grep '"tags".*"投资"' {原子库} | head -20

# 按内容关键词检索
grep -i '认知\|思维\|方法' {原子库} | head -20
```

选题时优先使用 `usage_count` 高的原子——这些是经过多次验证的核心观点，自带传播力。

```markdown

**Step 3：选题装配**

```
