## 课题 2：标题——信息压缩

### 核心原则

标题不是概括内容，是制造「必须点进去看看发生了什么」的冲动。

检验标准：读者看到标题后，会不会产生「然后呢？」的冲动。会就是好标题。

### 七大标题公式

| 公式 | 示例 |
|------|------|
| 反常识 + 数据 | 「我每天看 3 次账户，亏了 8 万才学会不看」 |
| 过程揭秘 | 「用了 30 天测试 5 种写法，哪种标题点击率最高？」 |
| 代价叙事 | 「为了搞懂这件事，我花了 6 个月和 5 万学费」 |
| 对比冲突 | 「A 和 B 都试了，90% 的人选错了」 |
| 直接判断 | 「关于 XXX，这是我最想告诉你的一件事」 |
| 提问式 | 「你有没有算过，自己每天花多少时间在 X 上？」 |
| 清单式 | 「3 个方法，让你的 Y 提升 Z%」 |

### 素材库联动：从金句到标题

金句弹药库中的「开篇钩子」和「观点锚点」可以直接改写成标题：

```
步骤：
1. 从 05_核心资产库/01_金句弹药库_v2.md 选取一条金句
2. 用「反常识+数据」或「对比冲突」公式改写
3. 控制在 20 字以内（小红书标准）
```

示例：
- 金句：「天天发推特讲赚钱的人，大部分不赚钱」
- 改写标题：「天天发推讲赚钱的人，大部分不赚钱」

### 高阅读量数据校准

用公众号历史高阅读量数据校准标题判断标准。数据来源：

```
踏雪素材库/05_核心资产库/公众号归档/分析/
├── 高阅读量Top50.md          — 50篇最高阅读文章的标题、阅读量、分类
├── 深度选题挖掘.md            — 留言互动最高 + 系列候选 + 付费专栏候选
├── 文风演变与创作流程综合报告.md — 13年文风变化趋势
└── 2025-2026年真人味文章统计与归纳.md — 高阅读量的共同特征
```

**校准方法**：

1. 诊断标题时，对比同分类的 Top50 标题结构
2. 提取高阅读量标题的共同模式（如下方「高阅读量标题 DNA」）
3. 如果用户标题和高阅读量标题结构一致，标记「合格」；偏离则给出具体调整建议

**高阅读量标题 DNA（从 Top50 提取）**：

| 模式 | 占比 | 示例 |
|------|------|------|
| 清单/推荐体 | 32% | 「那些值得珍藏的投资公众号」 |
| 对比/选择体 | 18% | 「沪深300和红利基金：两种投资哲学的抉择」 |
| 悬念/揭秘体 | 16% | 「基金江湖怪现状」 |
| 经验分享体 | 14% | 「我的全天候投资组合：均衡成长，全球配置」 |
| 问答/指南体 | 12% | 「基金解读指南：教你一眼看透手中基金的真实水平」 |
| 其他 | 8% | — |

**关键发现**：
- 最高阅读量的文章标题都不超过 20 字
- 「那些」「这些」「我的」是高频开头词——制造亲近感
- 数字和对比是第二高频元素——制造信息密度
- 标题中直接包含「你」的，互动率（留言）明显更高

### 标题 A/B 测试流程

1. 为同一篇内容写 3-5 个标题
2. 发布前让读者/朋友预判点击率
3. 选最高分的发布
4. 记录到标题测试记录表

### 标题 forbid-list

以下词出现在标题中 → 自动排除或重写：「再论」「浅谈」「也谈」「关于…的思考」「…之我见」。

验证：3 篇含「再论」的标题，3 篇在各自组内阅读排名后 50%。「再论」暗示「这是内部讨论」，对新读者是排斥信号。

### 标题+开头联合效用红线

```
联合效用 = 标题效用 + 开头效用

- ≥ 5.0：高效用组合
- 3.0-4.9：合格
- < 3.0：强制重写标题或开头

标题效用 = (承诺价值 × 交付确定性) / 认知摩擦
开头效用 = (信息增益预期 × 邻近性) / 耐心成本
```

验证：40 篇历史文章，联合效用 < 3.0 的，100%（10/10）阅读量组内排名后 40%。

## 课题 3：开头——认知钩子

### Hook 公式

```
Hook = 话题（讲什么）+ 痛点（为什么看）+ 可信度（为什么信你）
```

### 七大开头模式

| 模式 | 结构 | 示例 |
|------|------|------|
| 冲突开头 | 先说反直觉的事实 | 「所有人都说 X，但我花了 Y 年发现他们都错了」 |
| 故事开头 | 具体场景 | 「那天下午 3 点，我盯着账户看了 10 分钟」 |
| 结论开头 | 直接给判断 | 「关于 XXX，90% 的人都理解错了」 |
| 提问开头 | 让读者代入 | 「你有没有想过，为什么 X？」 |
| 数据开头 | 数字制造冲击 | 「X 天，Y 次实验，Z% 的失败率」 |
| 场景开头 | 读者熟悉的场景 | 「打开手机，看到又跌了 2%，你会怎么办？」 |
| 引用开头 | 一句话+解读 | 「查理·芒格说过一句话，我花了 5 年才真正理解」 |

### 素材库联动：开头弹药库

从素材库中提取开头素材：

```
1. 从原子库检索高 usage_count 的「认知差」类原子 → 用作认知钩子
2. 从金句弹药库「开篇钩子」中选取 → 直接用作开头
3. 从洞见观点库中选取反常识观点 → 制造冲突开头
```

### 开头检测清单

- [ ] 第一句话有没有制造好奇心或冲突？
- [ ] 前三行能不能让读者停下来？
- [ ] 有没有具体的时间/地点/数字/细节？
- [ ] 有没有废话可以删掉？
- [ ] 读完开头，读者会不会想「然后呢？」
- [ ] 开头和标题有没有呼应？

### 平台适配

| 平台 | 开头要求 | 注意事项 |
|------|---------|---------|
| 小红书 | 1-2 行必须钩住 | 移动端阅读，前三行决定生死 |
| 抖音 | 前 3 秒必须出声 | 视频开头需要强钩子 |
| 公众号 | 前一段制造悬念 | 可以稍长，但必须有节奏 |
| X/推特 | 第一句话就是钩子 | 信息流极快，没有第二次机会 |

## 课题 4：结构——逻辑链

### 内容结构模板

**短内容（小红书/朋友圈/推文）**：

```
钩子（1-2句）→ 核心观点（1句）→ 论据/案例（2-3个）→ 行动号召/金句收尾
```

**中内容（公众号文章/知乎回答）**：

```
开头钩子 → 为什么重要（背景）→ 我的判断（核心观点）→ 怎么来的（推导过程）→ 所以呢（行动建议）→ 结尾（不是总结，是按钮）
```

**长内容（系列/深度文/课程）**：

```
问题定义 → 为什么现有答案不够 → 我的框架 → 每个节点的论证 → 综合应用 → 下一步
```

### 见感思行框架

```
【见】具体场景开头，不给背景
【感】说出读者说不出的感受
【思】认知增量，每个论点让人意外
【行】明天就能做的第一步
```

### 结构检测清单

- [ ] 能用一句话说清核心观点吗？
- [ ] 每个段落推动读者往下读了吗？
- [ ] 有没有可以删掉但不影响理解的段落？
- [ ] 论据支撑观点了吗？
- [ ] 结尾是按钮，不是总结？

### 素材库联动：结构填充

从洞见观点库中提取「核心观点」作为结构节点，从原子库中提取「when_to_use」场景作为案例支撑。

### 工作站联动：内容单元库填充

当结构诊断发现某个段落缺乏支撑时，从内容单元库中提取弹药：

**检索路径**：

```
{工作站}/02-内容单元库/
├── 观点单元/（25篇）— 核心判断 → 用于「思」的段落
├── 案例单元/（21篇）— 真实经历 → 用于「见」和「感」的段落
├── 概念单元/（15篇）— 定义框架 → 用于「思」的理论支撑
├── 问题单元/（24篇）— 读者痛点 → 用于开头的痛点制造
└── 方案单元/（5篇）— 可执行步骤 → 用于「行」的段落
```

**装配规则**：

1. 每个内容单元都有 `themes` 和 `keywords` 字段，按选题主题匹配
2. 每个单元都有 `relationships` 字段，追踪与其他单元的「回应/解释/证明/冲突」关系
3. 多个单元可以按 `relationships` 的指向性串联，形成完整逻辑链
4. 装配时优先使用与选题主题匹配度最高的单元，跨主题装配时需标注引用关系
