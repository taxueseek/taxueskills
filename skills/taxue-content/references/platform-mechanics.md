# 平台机制速查

## 核心认知

每个平台本质是一台内容分发机器。它有自己独特的「燃料」——核心指标。理解这台机器如何运转，才能高效产出。

## 六平台机制拆解

### 小红书

**核心指标**：点击率（CTR）+ 收藏率

**分发逻辑**：
- 笔记发布后进入初始流量池（200-500 曝光）
- 系统根据标签匹配推给可能感兴趣的用户
- 互动率（点赞+评论+收藏）决定是否进入下一级流量池
- 收藏率是小红书最重要的深度指标

**内容偏好**：
- 实用干货、清单、经验分享
- 图文为主，9:16 竖版
- 标题要具体、有数字、有利益点
- 正文分段清晰，善用 Emoji 分隔

**关键策略**：
- 前 3 行决定点击率
- 收藏率 > 点赞率 > 评论率
- 评论区互动加权
- 发布后 1 小时内主动回复评论

### 抖音

**核心指标**：完播率 + 互动率

**分发逻辑**：
- 每条视频进入初始流量池（300-500 播放）
- 完播率决定是否进入下一级流量池（每级约翻倍）
- 互动率（点赞+评论+分享）是第二权重
- 流量池递进：300 → 3000 → 3万 → 30万 → 300万

**内容偏好**：
- 强节奏，前 3 秒必须有钩子
- 竖版 9:16
- 时长控制在 30-60 秒（新手）
- 字幕要大，颜色对比强

**关键策略**：
- 完播率是第一优先级
- 前 3 秒不能有任何废话
- 结尾留钩子引导评论
- 发布时间：早 7-9，中 12-14，晚 18-20

### 公众号

**核心指标**：打开率 + 分享率

**分发逻辑**：
- 基于订阅关系的推送（打开率 = 打开人数/送达人数）
- 社交分发：朋友圈分享带来二次传播
- 算法推荐：根据阅读行为推荐相似内容
- 搜一搜流量：标题关键词匹配搜索

**内容偏好**：
- 深度观点、长逻辑链
- 图文结合，排版舒适
- 标题要制造信息缺口
- 有节奏感，段落短、重点突出

**关键策略**：
- 标题决定打开率（和读者建立契约）
- 内容质量决定分享率
- 固定发布时间，培养读者习惯
- 引导「在看」和「分享」

### X/推特

**核心指标**：转发率 + 回复率

**分发逻辑**：
- 基于社交关系的 Timeline 分发
- 互动率高的内容进入 Explore/趋势
- Thread（推文串）形式有额外权重
- 话题标签和关键词匹配

**内容偏好**：
- 锐利观点、一句话判断
- Thread 形式做深度分析
- 互动性强，回复转发是核心
- 时效性：热点窗口期短

**关键策略**：
- 第一句话就是钩子
- Thread 第一推要有独立价值
- 主动互动，回复评论
- 固定发布时间，保持活跃度

### 知乎

**核心指标**：赞同率 + 收藏率

**分发逻辑**：
- 基于问题匹配的内容分发
- 回答质量加权（长文有优势）
- 赞同数影响排序
- 收藏数影响长期推荐

**内容偏好**：
- 深度分析、干货教程
- 有逻辑链的长文
- 数据支撑、案例丰富
- 标题直接回答问题

**关键策略**：
- 选对问题比写好回答重要
- 长文在知乎有天然优势
- 数据、引用、案例增加可信度
- 定期更新老回答，保持活跃度

### B站

**核心指标**：完播率 + 互动率

**分发逻辑**：
- 搜索 + 推荐双驱动
- 完播率是核心
- 三连（点赞+投币+收藏）加权
- 弹幕互动率影响推荐

**内容偏好**：
- 教程、深度内容
- 横版 16:9
- 时长灵活，深度内容可以长
- 封面和标题极其重要

**关键策略**：
- 标题和封面决定点击率
- 开头 30 秒留住观众
- 内容密度要高，不能水
- 定期更新，保持频道活跃度

## 多平台分发策略

### 内容改编原则

同一选题，适配不同平台的核心动作：

1. **拆解核心**：提取「核心观点 + 关键论据 + 数据/案例」
2. **平台适配**：根据平台偏好调整形式和长度
3. **差异发布**：不要完全一样的内容全平台发

### 改编示例

| 选题 | 公众号 | 小红书 | 抖音 | X/推特 |
|------|--------|--------|------|--------|
| 投资方法论 | 深度长文 | 清单体图文 | 60 秒口播 | Thread 拆解 |
| 案例分析 | 完整分析 | 关键结论+数据 | 故事化讲述 | 一句话判断+链接 |
| 工具推荐 | 详细评测 | 对比清单 | 30 秒演示 | 一句话推荐+截图 |
